Sẵn sàng.
Hướng dẫn sử dụng
1. Dán code userscript vào khung chỉnh sửa.
2. Nhấn “Tải file .user.js”.
3. Mở file bằng trình duyệt đã cài Tampermonkey hoặc nhập code vào trình quản lý userscript.
4. Kiểm tra các dòng @match để script chỉ chạy trên website bạn mong muốn.

Lưu ý: Trang này dùng để soạn thảo và tải code, không tự chạy code trên các website khác.
